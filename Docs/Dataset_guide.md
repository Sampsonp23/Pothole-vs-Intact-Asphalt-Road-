# Dataset Preparation Guide

Our dataset is the Road Anomaly Detection System Dataset from Mendeley Data.

## What the dataset contains

The dataset has two folders:

Pothole: 300 images of roads with potholes

Plain: 300 images of good quality roads

Total: 600 images

## How we split the data

We used an 80/20 split:

Training set: 480 images

Validation set: 120 images
