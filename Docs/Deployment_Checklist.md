# Deployment Checklist
Tick every box before we submit.
- [ ] The repository is public
- [ ] The trained model file is in the repo
- [ ] Every package the app needs is in requirements.txt
- [ ] The app runs on a laptop before we deploy it
- [ ] The live link opens with no login required
- [ ] Three different people opened the link and it worked
- [ ] At least one of them used mobile data, not wifi
- [ ] The link is in the README
